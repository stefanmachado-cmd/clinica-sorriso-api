# Clínica Sorriso API

## Cliente
Dr. Roberto (Sorriso Metálico)

## Objetivo do Sistema
Desenvolver uma API leve, rápida e de alta performance para a gestão de uma clínica odontológica de alto padrão.

## Requisitos Principais
- Bloqueio automatizado de horários nobres (como manhãs de sábado) exclusivamente para pacientes classificados como VIP, impedindo agendamentos comuns pela recepção.
- Prontuário eletrônico ágil que exiba visualmente o dente e o procedimento realizado logo na abertura da ficha do paciente.
- Interface moderna, elegante e sofisticada com validação única por CPF e níveis de acesso (VIP/Comum).
